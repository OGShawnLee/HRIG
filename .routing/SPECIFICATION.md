# Software Specification

> Refined software project specification for HRIG. Kept in Spanish and expanded incrementally until final delivery, when it will be translated to English.

## Requerimientos Funcionales

- **RF01:** El sistema debe mostrar un dashboard con la informacion primaria de salud en tiempo real del astronauta.
- **RF02:** El sistema debe registrar los datos recopilados del estado de salud en las historias clínicas de los astronautas.
- **RF03:** El sistema debe poder recibir y almacenar datos de los diferentes equipos de monitoreo de salud.
- **RF04:** El sistema debe explicar como tomar cada una de las medidas.
- **RF05:** El sistema debe mostrar la importancia de cada medida.
- **RF06:** El sistema debe mostrar qué hacer en caso de que una métrica presente un valor critico.
- **RF07:** El sistema debe de mostrar recomendaciones para normalizar un valor anomalo.
- **RF08:** El sistema debe mostrar una alerta a toda la tripulacion en caso de identificar un valor critico en el entorno o en algun miembro de la tripulacion.
- **RF09:** El sistema debe poder proporcionar las historias clinicas de los astronautas a sistemas verificados, autenticados y autorizados.
- **RF10:** El sistema debe mostrar un dashboard con informacion secundaria de la salud del astronauta.
- **RF11:** El sistema debe mostrar una figura anatomica responsiva que refleje el estado del astronauta.
- **RF12:** El sistema debe permitir seleccionar una extremidad en la figura anatómica y mostrar instrucciones para realizar procedimientos de esa extremidad.
- **RF13:** El sistema debe mostrar sintomatologia de una extremidad al seleccionarla en la figura anatomica.
- **RF14:** El sistema debe permitir que cada miembro de la tripulación tenga un perfil.
