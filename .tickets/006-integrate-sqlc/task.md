## Grounding & Anti-Hallucination Constraints

- **1:1 Schema Fidelity (`db/001_schema.sql`):**
  - Never modify `db/001_schema.sql`, `db/002_seed.sql`, or `db/003_demo_seed.sql`.
  - Point `sqlc.yaml` schema directly at `db/001_schema.sql` (`engine: "postgresql"`, `sql_package: "pgx/v5"`).
  - Do **not** invent tables, enums, or columns outside `db/001_schema.sql` (`astronaut`, `unit`, `metric`, `metric_threshold`, `device`, `measurement`, `measurement_value`, `media_asset`, and `v_astronaut_age`).
  - Keep generated bindings scoped cleanly in `server/internal/db/` (`package db`); do **not** wire HTTP routes or database startup into `server/cmd/server/main.go` or `server/internal/http/router.go` in this ticket.
- **SQLC CLI Baseline:**
  - Verified host CLI: `sqlc` (`v1.28.0`) on `PATH`.
  - Always verify regeneration via `wails3 task db:sqlc` from the repository root.
- **Do NOT commit or push** any changes to Git.

## Task

1. Create `sqlc.yaml` at the repository root configured for `version: "2"`:
   - `engine: "postgresql"`
   - `schema: ["db/001_schema.sql"]`
   - `queries: ["db/queries"]`
   - `gen.go`:
     - `package: "db"`
     - `out: "server/internal/db"`
     - `sql_package: "pgx/v5"`
     - `emit_json_tags: true`
     - `emit_interface: true`
     - `emit_empty_slices: true`
     - `emit_pointers_for_null_types: true`
2. Create SQLC query files under `db/queries/` covering `GUIDE.md` ingestion lookups/writes and core schema reads:
   - `db/queries/astronauts.sql`: `ListActiveAstronauts` (joining `astronaut` with `v_astronaut_age`), `GetAstronautByID`, `ListActiveAstronautsByFullName` (`:many`, filtering `full_name = $1 AND is_active = true`, so callers can detect zero or ambiguous duplicate active matches per `GUIDE.md`).
   - `db/queries/catalogs.sql`: `ListUnits`, `GetActiveUnitByCode` (`WHERE code = $1 AND is_active = true`), `ListActiveMetrics` (joining `metric` with base `unit` and `metric_threshold`, ordered by `display_order ASC`), `GetActiveMetricByCode` (`WHERE m.code = $1 AND m.is_active = true`, returning metric fields plus base unit `dimension` and `metric_threshold` limits), `GetThresholdByMetricCode`, `ListActiveDevices`, `GetActiveDeviceByCode` (`WHERE code = $1 AND is_active = true`).
   - `db/queries/telemetry.sql`: `CreateMeasurement`, `CreateMeasurementValue`, `CreateMediaAsset`, `ListLatestReadingsByMetric` (latest row per `(metric_id, astronaut_id)` using `recorded_at_utc DESC`), `ListTrendsByMetric` (filtered by `metric.code`, optional `astronaut_id`), `ListHistory` (recent measurements + values + optional media).
3. Add `github.com/jackc/pgx/v5` to `server/go.mod` (`go get github.com/jackc/pgx/v5` inside `server/`).
4. Verify `Taskfile.yml` defines `db:sqlc` (`sqlc generate`) cleanly and run `wails3 task db:sqlc` from repository root to generate `server/internal/db/*.go` (`db.go`, `models.go`, `querier.go`, `astronauts.sql.go`, `catalogs.sql.go`, `telemetry.sql.go`).
5. Run `go mod tidy` inside `server/` (if needed) and verify `wails3 task server:check` and `wails3 task client:check` both exit `0`. (If `wails3 task client:check` dirties `app/frontend/bindings/`, restore via `git checkout -- app/frontend/bindings/`.)
6. Write `.tickets/006-integrate-sqlc/changelog.md` listing all files created/modified and exact verification command outputs.
