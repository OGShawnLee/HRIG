# 016E — Changelog

## Summary of Changes

1. **`app/frontend/src/views/SearchView.vue`**
   - **Satoshi Typography (`font-sans`):** Added `font-sans` to the root `<main>`, `ComboboxInput` (`#hrig-omnibox-input`), all `<button>` controls (`Clear`, `Close`, category tabs, `Retry`, `Reset filters`, footer `Esc Close`), and all `<kbd>` elements (`Ctrl + K`, `↑`, `↓`, `Enter`, `Esc`). Replaced all occurrences of `font-mono` with `font-sans` while preserving `tabular-nums` on counts and numeric values.
   - **Rounded HUD Geometry:** Applied `rounded-2xl overflow-hidden` to the outer Omnibox container (`omniboxContainerRef`), `rounded-xl` to category tabs, `Close` button, `Reset filters` button, and all four `ComboboxItem` groups (`Crew`, `Metrics`, `Medical Procedures`, `NASA Hazards`), `rounded-lg` to `Clear` and `Retry` buttons, and `rounded-md` to inline metadata tags/badges and `<kbd>` keycaps.
   - **All-Crew Metric Readouts (`metricLiveRows`):** Replaced single-astronaut `metricLiveSummary` with `metricLiveRows(metric)` returning `{ key, label, display, status }` for every astronaut in `activeAstronauts` (or `{ key: "env", label: "Cabin / Suit", display, status }` when `metric.metricType === 2`). Updated `Metrics` `<ComboboxItem>` cards to display each row with member/sensor label, tabular value (`hud-value`), status color, and status icon (`CheckCircle2`, `AlertTriangle`, `AlertCircle`, `WifiOff`, `Minus`).
   - **Query-Active Group Ordering:** Added `hasActiveQuery` (`query.trim().length > 0`) and `visibleGroupOrder` so `Metrics` renders directly after `Crew` and before `Medical Procedures` and `NASA Hazards` when a query is active, keeping `entriesByKey` insertion order synchronized (`astronauts -> metrics -> procedures -> hazards` when `hasActiveQuery`, otherwise `astronauts -> procedures -> hazards -> metrics`).

2. **`app/frontend/src/components/SearchFeaturedEntry.vue`**
   - **Satoshi Typography (`font-sans`):** Added `font-sans` to the root `<aside>` and `<button>` controls, and replaced every occurrence of `font-mono` (related metric chips, procedure code footer, hazard code, metric unit badge, metric code subtitle, `MET` timestamp) with `font-sans` (preserving `tabular-nums` on `MET` and numeric values).
   - **Rounded HUD Geometry:** Removed `rounded-none` from all three `.button-main` CTA buttons (`Open Primary Vitals`, `View Matching Procedures`, `View Procedures for <metric>`) so they inherit `.button-main`'s `rounded-xl`. Applied `rounded-xl` to all inner section panels and checklist step `<li>` cards; `rounded-lg` to step index badges (`1..N`), escalation badge, `~N min` pill, equipment pills, clickable metric/hazard filter chips, `Unpin` button, and live telemetry status badge; and `rounded-md` to compact metadata tags (`Active Checklist`, `Pinned`, `Crew`, `Active`/`Inactive`, `category`/`bodySystem`/`environment`, `NASA HRP Hazard`, `Crew Metric`/`Environment Metric`, `Tier`, and unit tag).
