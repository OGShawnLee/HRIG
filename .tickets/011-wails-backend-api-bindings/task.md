## Grounding & Anti-Hallucination Constraints

- **Module Independence & Shared Types:**
  - `app/go.mod` must compile identically inside `go.work` and with `GOWORK=off` (`require hrig/shared v0.0.0` + `replace hrig/shared => ../shared`).
  - Use canonical `hrig/shared/model` types (`model.Astronaut`, `model.Metric`, `model.Snapshot`, `model.TrendQuery`, `model.TrendPoint`, `model.HistoryQuery`, `model.HistoryEntry`, `model.AckAlertRequest`, `model.AlertEvent`, `model.HealthStatus`, `model.RealtimeEnvelope`) directly in bound `*App` method signatures so `wails3 generate bindings` produces strongly typed TypeScript interfaces.
- **WebSocket Library & Event Contract:**
  - Use `github.com/coder/websocket` (already present in `app/go.mod`) and `encoding/json` / `net/http` — do **not** add `gorilla/websocket` or third-party HTTP wrappers to `app/go.mod`.
  - Read base server URL from `HRIG_API_URL`, defaulting to `"http://127.0.0.1:80"` (trim trailing `/`, validate `http`/`https` scheme, derive `ws://` or `wss://` + `/ws/realtime`).
  - Emit Wails custom events using safe event dispatch (`application.Get().Event.Emit(...)` when `application.Get() != nil`, or injected `emitFn` during tests):
    - `"telemetry:envelope"` carrying `model.RealtimeEnvelope`
    - `"telemetry:connection"` carrying `ConnectionState` (`Connected bool`, `URL string`, `LastError string`, `UpdatedAtUTC time.Time`)
- **Non-Blocking Lifecycle & Preserve Existing Bindings:**
  - Preserve `NewApp() *App`, `SetContext(ctx context.Context)`, `Ping() string`, `OnMinimize()`, `OnMaximize()`, and `OnClose()`.
  - Implement Wails v3 `ServiceStartup(ctx context.Context, options application.ServiceOptions) error` and `ServiceShutdown() error` on `*App`. Never block `ServiceStartup` waiting for `server/` to be reachable — launch the WS bridge in a background goroutine with clean cancellation and exponential backoff (`1s` → `2s` → `5s` cap).
- **Wails v3 Build Rules:**
  - Never run `go build ./...` inside `app/`; use `go build .` (or `wails3 task client:check`).
  - Clean up any temporary binary if `go build .` writes `app/app.exe` (keep only `app/bin/` artifacts if generated by `wails3 task build`).
  - Do **not** commit or push changes.

## Task

1. **Wire `hrig/shared` & `github.com/coder/websocket` in `app/go.mod`:**
   - Add `hrig/shared v0.0.0` + `replace hrig/shared => ../shared` and direct `require github.com/coder/websocket v1.8.14` in `app/go.mod`.
2. **Create `app/client.go`:**
   - Define `ConnectionState`:
     - `Connected bool` (`json:"connected"`)
     - `URL string` (`json:"url"`)
     - `LastError string` (`json:"lastError"`)
     - `UpdatedAtUTC time.Time` (`json:"updatedAtUtc"`)
   - Define `apiClient` struct holding `baseURL string`, `wsURL string`, `httpClient *http.Client` (`8 * time.Second` timeout), `mu sync.RWMutex`, `connState ConnectionState`, and `emitFn func(name string, data any)`.
   - Implement `resolveAPIBaseURL(raw string) (httpBase string, wsURL string, err error)` normalizing defaults (`http://127.0.0.1:80` -> `ws://127.0.0.1:80/ws/realtime`).
   - Implement typed REST methods on `*apiClient`:
     - `GetHealth(ctx context.Context) (model.HealthStatus, error)` → `GET /health`
     - `GetAstronauts(ctx context.Context) ([]model.Astronaut, error)` → `GET /api/astronauts`
     - `GetMetrics(ctx context.Context) ([]model.Metric, error)` → `GET /api/metrics`
     - `GetSnapshot(ctx context.Context) (model.Snapshot, error)` → `GET /api/snapshot`
     - `GetTrends(ctx context.Context, query model.TrendQuery) ([]model.TrendPoint, error)` → `GET /api/trends` encoding non-empty `metric_code`, optional `astronaut_id`, and `limit > 0`
     - `GetHistory(ctx context.Context, query model.HistoryQuery) ([]model.HistoryEntry, error)` → `GET /api/history` encoding optional `astronaut_id`, `limit > 0`, and `offset > 0`
     - `AckAlert(ctx context.Context, alertID, acknowledgedBy string) (model.AlertEvent, error)` → `POST /api/alerts/{id}/ack` with `model.AckAlertRequest` JSON body (returning validation error if `strings.TrimSpace(alertID) == ""`)
   - Extract server JSON `{"error":"..."}` on HTTP status `>= 400` into clear Go `error` values.
   - Implement `RunRealtimeLoop(ctx context.Context)` connecting to `wsURL` via `websocket.Dial(ctx, wsURL, nil)`, reading JSON `model.RealtimeEnvelope` frames in a loop, updating `ConnectionState`, emitting `"telemetry:connection"` on state changes, emitting `"telemetry:envelope"` on each frame, and reconnecting cleanly on disconnect/error with bounded backoff (`1s`, `2s`, `5s`) until `ctx.Done()`.
   - Expose `SendWSAlertAck` or keep `AckAlert` over REST (`POST /api/alerts/{id}/ack` is canonical and deterministic).
3. **Update `app/app.go` with Wails v3 Service Lifecycle & Bound Methods:**
   - Store `client *apiClient`, `cancel context.CancelFunc`, and `wg sync.WaitGroup` on `App` (initialized in `NewApp()`).
   - Implement `ServiceStartup(ctx context.Context, _ application.ServiceOptions) error`: store `a.ctx = ctx`, wire event emitter (`application.Get().Event.Emit`), create cancellable child context, start `a.wg.Add(1)` + `go a.client.RunRealtimeLoop(wsCtx)` without blocking startup.
   - Implement `ServiceShutdown() error`: invoke `cancel()` and `a.wg.Wait()` cleanly.
   - Add bound methods on `*App`:
     - `GetConnectionStatus() ConnectionState`
     - `GetHealth() (model.HealthStatus, error)`
     - `GetAstronauts() ([]model.Astronaut, error)`
     - `GetMetrics() ([]model.Metric, error)`
     - `GetSnapshot() (model.Snapshot, error)`
     - `GetTrends(query model.TrendQuery) ([]model.TrendPoint, error)`
     - `GetHistory(query model.HistoryQuery) ([]model.HistoryEntry, error)`
     - `AckAlert(alertID string, acknowledgedBy string) (model.AlertEvent, error)`
   - Guard each RPC method against `a.ctx == nil` by falling back to `context.Background()` with timeout.
4. **Write Unit Tests in `app/client_test.go` & Verify Bindings + Full Client Build:**
   - Test `resolveAPIBaseURL` (`http`, `https`, trailing slashes, empty default, invalid scheme).
   - Stand up an `httptest.Server` implementing `/health`, `/api/astronauts`, `/api/metrics`, `/api/snapshot`, `/api/trends`, `/api/history`, `/api/alerts/{id}/ack`, HTTP `400` error decoding, and a live WebSocket endpoint (`/ws/realtime` via `github.com/coder/websocket`) sending initial `"snapshot"` + `"reading"` + `"alert"` envelopes.
   - Verify `*App` bound methods decode responses accurately and `RunRealtimeLoop` emits `"telemetry:connection"` (`Connected: true`) + `"telemetry:envelope"` frames and exits cleanly when canceled.
   - Run `go -C app mod tidy`, `GOWORK=off go -C app vet .`, `go -C app test -v -count=1 ./...`, and `wails3 task client:check` (confirming regenerated `app/frontend/bindings/hrig/app/app.ts` and `app/frontend/bindings/hrig/shared/model/models.ts` contain the new functions & types, `bun run --cwd frontend type-check` passes, `vite build` passes, and `go build .` exits `0`). Remove any stray `app/app.exe` if present after checks.
