# Bare-Bones Wails v3 Desktop App Scaffolding Guide

A self-contained blueprint for scaffolding a minimal **Wails v3 + Go + Vue 3 + Vite + Bun + UnoCSS + TypeScript** desktop application matching the architecture and tooling of Palabrario's `app/`. Designed to be handed directly to an agent router (or turned into a scaffolding ticket) in a new project.

---

## 1. Target Stack & Baseline Versions

| Layer | Technology | Version / Notes |
| :--- | :--- | :--- |
| **Desktop Shell** | Wails v3 (`github.com/wailsapp/wails/v3`) | `v3.0.0` + `@wailsio/runtime` `3.0.0` |
| **Go Toolchain** | Go | `1.24+` (Palabrario uses `1.26.0`) |
| **Frontend Framework** | Vue 3 + Vue Router | `vue ^3.5`, `vue-router ^5.4` (hash history) |
| **Bundler & Package Manager** | Vite + Bun | `vite ^8.x`, `bun` as `PACKAGE_MANAGER` |
| **Type Checking** | TypeScript + `vue-tsc` | **`typescript >= 5.7`** (required for `bundler` + `verbatimModuleSyntax`) |
| **CSS Engine** | UnoCSS (`unocss ^66.x`) | `presetWind3`, `presetWebFonts`, `transformerDirectives`, `@unocss/reset` |
| **Icons & Headless UI (Optional)** | `lucide-vue-next`, `reka-ui`, `@vueuse/core` | Include only if your UI uses them |
| **Task Runner** | Wails built-in Taskfile | Always invoke via `wails3 task <name>` |

---

## 2. Prerequisites on Host Machine

Before running the scaffold:
1. **Go** installed (`go version` >= `1.24`).
2. **Wails v3 CLI** installed (`wails3 version`).
3. **Bun** installed (`bun --version`).
4. **Platform native WebView** (WebView2 on Windows 10/11, WebKitGTK on Linux, WKWebView on macOS).

## 4. Step-by-Step Scaffolding Instructions

> [!IMPORTANT]
> Replace placeholders `<project>`, `<ProjectName>`, `<com.example.app>`, and `<app_binary>` with your target project values consistently across `go.mod`, `vite.config.ts`, `WindowBar.vue`, `Taskfile.yml`, and `build/config.yml`.

### Step 1 — Generate the Base Wails v3 Template

Run from `<repo-root>`:

```bash
wails3 init -n app -t vue -mod <project>/app -skipgomodtidy -q
```

- **Do NOT pass `-d app`:** `wails3 init -n app -d app` nests the project at `app/app/`.
- **If the repo uses `go.work` (monorepo):** immediately register the new module from `<repo-root>`:

  ```bash
  go work use ./app
  ```

  Without this, `wails3 generate bindings` silently emits `0 Services, 0 Methods` and frontend imports from `@bindings/...` fail.

---

### Step 2 — Prune Dead Template Files

Delete template artifacts that conflict with `go build` or bloat the bare-bones frontend:

1. Delete `app/greetservice.go`.
2. Delete `app/build/ios/`, `app/build/android/`, and `app/build/docker/` (dead stubs in Wails templates that break `go build ./...`).
3. Delete everything inside `app/frontend/src/`.
4. Delete unused template assets in `app/frontend/`:
   - `app/frontend/public/style.css`
   - `app/frontend/public/bg-desktop.jpg`, `bg-mobile.jpg`, `vue.svg`, `Inter-Medium.ttf`
   - `app/frontend/Inter Font License.txt`, `app/frontend/README.md`
   - Keep `app/frontend/public/wails.png` (or replace with your own favicon).

---

### Step 3 — Fix `.gitignore` for `app/build/`

If your root `.gitignore` has a broad `build/` rule, add a negation right beneath it so Wails platform config and icons remain tracked:

```gitignore
bin/
dist/
build/
!app/build/
```

### Step 4 — Configure Go Backend Entrypoint (`app/`)

#### 4.1 `app/go.mod`

Ensure the module name matches `<project>/app` and pins Wails v3:

```go
module <project>/app

go 1.24.0

require (
	github.com/wailsapp/wails/v3 v3.0.0
)
```

*(Run `go mod tidy` inside `app/` once `main.go` and `app.go` are in place.)*

#### 4.2 `app/app.go`

Minimal service struct exposed to Wails bindings:

```go
package main

import "context"

type App struct {
	ctx context.Context
}

func NewApp() *App {
	return &App{}
}

func (a *App) SetContext(ctx context.Context) {
	a.ctx = ctx
}

func (a *App) Ping() string {
	return "pong"
}
```

#### 4.3 `app/app_window.go` (for Frameless Windows)

```go
package main

import "github.com/wailsapp/wails/v3/pkg/application"

func (a *App) OnMinimize() {
	if app := application.Get(); app != nil {
		if w := app.Window.Current(); w != nil {
			w.Minimise()
		}
	}
}

func (a *App) OnMaximize() {
	if app := application.Get(); app != nil {
		if w := app.Window.Current(); w != nil {
			w.ToggleMaximise()
		}
	}
}

func (a *App) OnClose() {
	if app := application.Get(); app != nil {
		app.Quit()
	}
}
```

#### 4.4 `app/main.go`

```go
package main

import (
	"context"
	"embed"
	"log"

	"github.com/wailsapp/wails/v3/pkg/application"
)

//go:embed all:frontend/dist
var assets embed.FS

func main() {
	appService := NewApp()

	app := application.New(application.Options{
		Name:        "<ProjectName>",
		Description: "<Project description>",
		Services: []application.Service{
			application.NewService(appService),
		},
		Assets: application.AssetOptions{
			Handler: application.AssetFileServerFS(assets),
		},
		Mac: application.MacOptions{
			ApplicationShouldTerminateAfterLastWindowClosed: true,
		},
	})

	appService.SetContext(context.Background())

	app.Window.NewWithOptions(application.WebviewWindowOptions{
		Title:            "<ProjectName>",
		Width:            1280,
		Height:           820,
		MinWidth:         390,
		MinHeight:        680,
		Frameless:        true,
		BackgroundColour: application.NewRGB(255, 255, 255),
		URL:              "/",
		Mac: application.MacWindow{
			InvisibleTitleBarHeight: 50,
			Backdrop:                application.MacBackdropTranslucent,
			TitleBar:                application.MacTitleBarHiddenInset,
		},
	})

	if err := app.Run(); err != nil {
		log.Fatal(err)
	}
}
```

> **Note:** Set `Frameless: false` and omit `app_window.go` / `WindowBar.vue` if you prefer native OS window chrome.

#### 5.4 `app/frontend/vite.config.ts`

```ts
import Vue from "@vitejs/plugin-vue"
import UnoCSS from "unocss/vite"
import Wails from "@wailsio/runtime/plugins/vite"
import path from "node:path"
import { fileURLToPath } from "node:url"
import { defineConfig } from "vite"

const currentDir = import.meta.dirname ?? path.dirname(fileURLToPath(import.meta.url))

export default defineConfig({
  plugins: [
    Vue(),
    UnoCSS(),
    Wails("./bindings"),
  ],
  resolve: {
    alias: {
      "@": path.resolve(currentDir, "./src"),
      "@bindings": path.resolve(currentDir, "./bindings"),
    },
  },
  server: {
    host: "127.0.0.1",
    port: Number(process.env.WAILS_VITE_PORT) || 9245,
    strictPort: true,
  },
})
```

#### 5.5 `app/frontend/uno.config.ts`

Minimal UnoCSS setup with `presetWind3`, Fontshare `Satoshi`, `--uno` directives, and baseline monochrome tokens/shortcuts:

```ts
import { defineConfig, presetWind3, presetWebFonts, transformerDirectives } from "unocss"

export default defineConfig({
  presets: [
    presetWind3(),
    presetWebFonts({
      provider: "fontshare",
      fonts: {
        sans: "Satoshi",
      },
    }),
  ],
  transformers: [
    transformerDirectives({
      applyVariable: "--uno",
    }),
  ],
  theme: {
    colors: {
      main: "black",
      side: "#404040",
      dull: "#737373",
      ground: "#FAFAFA",
      light: "#F5F5F5",
    },
  },
  shortcuts: {
    button: "h-12 min-w-fit px-4 border border-black border-solid rounded-none inline-flex items-center justify-center disabled:opacity-50",
    "button-main": "button bg-main font-medium text-white",
    "button-side": "button bg-ground text-main",
    field: "h-12 px-4 border border-solid border-dull rounded-none font-medium placeholder-dull disabled:opacity-50",
  },
})
```

> **Offline note:** `presetWebFonts` (`provider: "fontshare"`) fetches Satoshi from `cdn.fontshare.com` at runtime. If your app must run offline, self-host the `.woff2` files in `public/fonts/` and declare `@font-face` instead.

### Step 6 — Create the Minimal Vue 3 Application (`app/frontend/src/`)

#### 6.1 `src/vite-env.d.ts`

```ts
/// <reference types="vite/client" />
```

#### 6.2 `src/main.ts`

Import `virtual:uno.css` **before** `@unocss/reset/tailwind-compat.css`:

```ts
import "virtual:uno.css"
import "@unocss/reset/tailwind-compat.css"
import { createApp } from "vue"
import App from "./App.vue"
import router from "./router"

createApp(App).use(router).mount("#app")
```

#### 6.3 `src/router/index.ts`

Use `createWebHashHistory()` so embedded Wails asset URLs resolve reliably on every route:

```ts
import { createRouter, createWebHashHistory } from "vue-router"
import HomeView from "@/views/HomeView.vue"

const router = createRouter({
  history: createWebHashHistory(),
  routes: [
    { path: "/", name: "home", component: HomeView },
  ],
})

export default router
```

### Step 7 — Configure Taskfiles & App Metadata

#### 7.1 `app/Taskfile.yml`

```yaml
version: '3'

vars:
  APP_NAME: "<app_binary>"
  BIN_DIR: "bin"
  PACKAGE_MANAGER: '{{.PACKAGE_MANAGER | default "bun"}}'
  VITE_PORT: '{{.WAILS_VITE_PORT | default 9245}}'
  GOOS: '{{.GOOS | default OS}}'

includes:
  common: ./build/Taskfile.yml
  windows: ./build/windows/Taskfile.yml
  darwin: ./build/darwin/Taskfile.yml
  linux: ./build/linux/Taskfile.yml

tasks:
  build:
    summary: Build the desktop application
    cmds:
      - task: "{{.GOOS}}:build"

  package:
    summary: Package the production release
    cmds:
      - task: "{{.GOOS}}:package"

  run:
    summary: Run the compiled binary
    cmds:
      - task: "{{.GOOS}}:run"

  start:
    summary: Build and launch the application
    cmds:
      - task: build
      - task: run

  dev:
    summary: Live development mode (Vite + Wails hot-reload)
    cmds:
      - wails3 dev -config ./build/config.yml -port {{.VITE_PORT}}

  bindings:
    summary: Regenerate TypeScript bindings from Go
    cmds:
      - wails3 generate bindings -clean=true -ts

  check:
    summary: Full client verification (Bindings + Type-check + Vite + Go)
    cmds:
      - task: bindings
      - bun run --cwd frontend type-check
      - bun run --cwd frontend build
      - go build .
```

## 5. Verification Checklist

Run these commands in order and confirm every check passes:

```bash
# 1. Install frontend dependencies
cd app/frontend && bun install

# 2. Tidy Go dependencies
cd .. && go mod tidy

# 3. Run full check pipeline (bindings -> vue-tsc -> vite build -> go build .)
wails3 task check
```

Expected pass criteria:
1. `app/frontend/bindings/<project>/app/app.ts` exists and exports `Ping`, `OnMinimize`, `OnMaximize`, `OnClose`.
2. `bun run --cwd frontend type-check` exits `0`.
3. `bun run --cwd frontend build` creates `app/frontend/dist/index.html` and exits `0`.
4. `go build .` inside `app/` exits `0`.
5. `wails3 task dev` opens the desktop window with Vite on `http://127.0.0.1:9245`, and clicking **Test Go Bridge** updates the label from `Ready` to `pong`.

## 6. Traps & Agent Router Rules to Carry Over

| Pitfall | Why it happens | Mandatory Rule |
| :--- | :--- | :--- |
| **Empty bindings (`0 Services, 0 Methods`)** | `app/` has its own `go.mod` in a repo with `go.work`, but isn't listed in `go.work`. | Run `go work use ./app` before generating bindings. |
| **`go build ./...` fails inside `app/`** | `app/build/*` or packaging stubs don't contain `package main`. | Always run `go build .` inside `app/`, never `go build ./...`. |
| **Using `wails3 init -d app`** | Creates a nested `app/app/` directory. | Run `wails3 init -n app ...` from repo root without `-d`. |
| **`vue-tsc` fails on `bundler` / `verbatimModuleSyntax`** | Wails templates sometimes ship TypeScript `< 5.0`. | Pin `"typescript": "^5.7.3"` or higher. |
| **Running `task` instead of `wails3 task`** | Standalone `task` binary may differ or miss Wails environment vars. | Always invoke `wails3 task <name>`. |
| **CSS reset overrides utilities** | Importing `@unocss/reset` before `virtual:uno.css` changes cascade order, or vice versa. | Keep `"virtual:uno.css"` first, then `"@unocss/reset/tailwind-compat.css"` in `main.ts`. |
| **Direct `@bindings/` imports in views** | Tightly couples views to Wails desktop runtime if you later add web/Capacitor adapters. | Keep `@bindings/` calls isolated to `WindowBar.vue` and an `src/api/` adapter layer once you add domain features. |
| **`uno.config.ts` sprawl** | Feature workers inventing ad-hoc shortcuts or tokens per view. | Keep `uno.config.ts` router-governed: workers log proposed shortcuts/tokens instead of editing it unilaterally. |
| **`app/build/` missing after clone** | Root `.gitignore` has `build/`. | Add `!app/build/` to root `.gitignore`. |
